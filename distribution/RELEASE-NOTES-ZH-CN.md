## HarborProxy 0.1.1-rc.2

- 修复 Windows 私有配置加载后未应用本机端口、模式和 TUN 设置的问题。
- 系统代理会等待本地代理端口就绪；监听失败时保持系统代理关闭，避免直接断网。
- 修复核心运行时更新 `allow-lan`，并增强 TUN 参数缺失时的容错。
- 修复 Linux/macOS 系统代理的配置顺序和失败回滚，避免半配置状态导致断网；Linux
  只修改当前桌面实际支持的代理后端。
- Linux 授权时密码不再进入命令行；桌面 core 以 setuid 运行时，加密 session 与配置缓存
  仍归当前用户所有，重启后可以继续登录和使用离线缓存。
- macOS 系统代理启停合并为一次管理员授权，关闭状态下不再重复弹授权提示。
- Linux DEB 改为依赖运行库而非开发包，并修复 Go core 源码更新后打包仍复用旧二进制的问题。

## HarborProxy 0.1.0-rc.1

首个私有候选版，供内部安装测试。

- 品牌名称和跨平台图标统一为 HarborProxy。
- Android 使用独立正式包名和长期更新签名，提供单个通用 APK。
- Windows 提供免安装便携 ZIP；未购买代码签名证书。
- macOS 分 Intel 与 Apple Silicon 两个 DMG，使用 ad-hoc 签名，未做 Apple 公证。
- Linux 提供 amd64 DEB。
- 登录后由服务端生成并加密下发配置；本地只保留加密缓存，离线仍可使用上次成功配置。
- 保留自定义域名、IP、应用、脚本与规则集等本地路由能力，同时隐藏服务端节点详情。
- 启动时不再自动添加 VPN 卡片；仍使用主页右下角启动按钮。

安装前请阅读随包附带的 `INSTALL-ZH-CN.txt`。

本候选版基于 GPLv3 的 FlClash 修改，仅供内部测试。对外分发二进制前，必须同时向
接收者提供对应源码及 GPLv3 许可证。
